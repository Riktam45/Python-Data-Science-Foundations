# Python for Data Science - Coursework & Projects

This repository tracks my progress through the **Internshala Python with Data Science** training. It showcases my transition from core programming logic to data manipulation using NumPy.

# Key Topics Covered
Python Fundamentals: Mastering Lists, Tuples, Dictionaries, and Dictionay methods like `.keys()` and `.items()`.
Control Flow: Implementation of conditional logic (`if-elif-else`) and loops (`while`, `for`) to solve mathematical problems.
Algorithm Logic: Factorial calculation, searching elements in lists, and using `break`/`continue` efficiently.

# Data Science with NumPy
A major focus of this repo is utilizing **NumPy** for high-performance numerical computing:
Vectorization & Broadcasting: Performing element-wise operations and adding scalars to arrays.
Real-world Case Study: Analyzed temperature data for 5 Indian cities (Bangalore, Delhi, Chennai, Kolkata, Mumbai) to calculate daily averages and identify city-specific temperature anomalies.
Advanced Indexing: Extracting specific data points (like even numbers) from 2D arrays.

Language: Python 3
